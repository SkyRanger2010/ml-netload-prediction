# Changelog

Все заметные изменения проекта фиксируются в этом файле.

## [0.1.0] - 2025-11-16
### Added
- Первоначальная версия проекта.
- Базовая структура репозитория.
- README.md с описанием архитектуры, цели и пайплайнов.
- Начальная структура данных (raw/processed).
- Базовый ML-пайплайн: подготовка данных, обучение, оценка.
- Интеграция DVC для версионирования данных.
- MLflow для логирования экспериментов.
- FastAPI-сервис для инференса.
- Dockerfile и окружение для контейнеризации.
- Начальная конфигурация CI/CD.
- Базовый мониторинг (метрики сервиса + заглушки метрик модели).
