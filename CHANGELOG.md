# Changelog

Все заметные изменения проекта фиксируются в этом файле.

## [0.2.0] - 2025-12-05
### Added
- Полноценные скрипты подготовки данных, генерации признаков и обучения модели.
- FastAPI-сервис `api/app.py` на базе общего класса `NetworkLoadForecaster`.
- Интеграционные тесты на `pytest` и GitHub Actions workflow.
- Dockerfile для запуска сервиса и файл `dvc.yaml` с пайплайном.
- Конфигурация `configs/base.yaml`, requirements и документация по запуску.

### Changed
- README дополнен инструкциями по обучению, тестированию и запуску API.
- .gitignore обновлён для исключения обученных артефактов.

## [0.1.0] - 2025-11-16
### Added
- Первоначальная версия проекта.
- Базовая структура репозитория.
- README.md с описанием архитектуры, цели и пайплайнов.
- Начальная структура данных (raw/processed).
- Базовый ML-пайплайн: подготовка данных, обучение, оценка.
- Интеграция DVC для версионирования данных.
- MLflow для логирования экспериментов.
- FastAPI-сервис для инференса.
- Dockerfile и окружение для контейнеризации.
- Начальная конфигурация CI/CD.
- Базовый мониторинг (метрики сервиса + заглушки метрик модели).

### Planned
- Добавление реальных данных сети.
- Улучшение модели (временные ряды, дополнительные фичи).
- Настройка алертинга.
- Канареечные релизы.
- Нагрузочное тестирование.
