# **Система прогнозирования сетевой нагрузки**

## **Описание проекта**

Проект предназначен для прогнозирования сетевой нагрузки на узел связи
на основе исторических телеметрических данных.\
Модель предсказывает ожидаемую загрузку на ближайшие интервалы времени и
помогает выявлять потенциальные пики, перегрузки и аномалии.

Решение построено по принципам промышленного MLOps: воспроизводимость,
автоматизация, CI/CD, контейнеризация, управление версиями моделей и
мониторинг состояния системы.

## **Цель проекта**

Создать надёжный ML-сервис, который: - прогнозирует нагрузку с заданным
горизонтом; - автоматически обновляется при появлении новых данных; -
контролирует дрейф данных и качество модели; - разворачивается через
CI/CD и обеспечивает стабильную работу в продакшене.

## **Задачи**

-   Сбор, анализ и версионирование данных (DVC).\
-   Исследование временных паттернов и сезонности.\
-   Построение и сравнение моделей.\
-   Ведение экспериментов и артефактов (MLflow).\
-   Создание воспроизводимого ML-пайплайна.\
-   Контейнеризация inference-сервиса (FastAPI + Docker).\
-   Настройка автоматического CI/CD.\
-   Мониторинг технических и ML-метрик.

## **Как запустить**

### 1. Установка зависимостей

    pip install -r requirements.txt

### 2. Подготовка данных

    dvc pull
    python src/data/prepare.py

### 3. Обучение модели

    python src/models/train.py

### 4. Запуск API сервиса

    uvicorn api.app:app --reload

## **API**

### **POST /predict**

Принимает признаки узла --- возвращает прогноз нагрузки.

Документация доступна по адресу:

    /docs

## **Мониторинг**

Отслеживаем: - latency, throughput, error rate; - использование ресурсов
CPU/RAM/Disk; - дата- и концепт-дрифт; - метрики модели (MAE/RMSE); -
распределения признаков и аномалии.

Уведомления отправляются при нарушении SLA или деградации качества.
